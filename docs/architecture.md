# Архітектура AI-агента

## Призначення

Агент автоматизує типові етапи підготовки Python-проєкту: створення його структури, налаштування збирання та тестів, а також підготовку CI/CD.

## Skills

- `project-scaffold` — створення структури проєкту та початкових файлів.
- `build-and-test` — налаштування збирання і запуск тестів через `pytest`.
- `github-actions` — підготовка CI/CD для GitHub Actions.

## Доступні команди

- `git-init` — ініціалізація Git-репозиторію.
- `create-project` — створення структури проєкту.
- `create-build` — налаштування збирання та тестування.
- `create-actions` — налаштування CI/CD.
- `check` — перевірка результатів.
- `init` — запуск початкової ініціалізації й оркестрації етапів.

## Передавання даних між етапами

Оркестратор передає результат кожного етапу наступному як контекст: шлях і структура проєкту, створені файли та налаштування. Етапи збірки й тестування використовують цей контекст, а етап CI/CD — перевірені команди та конфігурацію. Команда `check` перевіряє підсумковий результат.

## Обробка помилок

Якщо будь-який етап завершується помилкою, оркестратор зупиняє подальше виконання та повідомляє про помилку. Наступні етапи не запускаються, щоб не будувати результат на неповних або некоректних даних.
